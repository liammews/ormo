This page is a sandbox. Each example below is intentionally invalid so the Ormo development toolbar has something to report.

Start the docs site with <code>pnpm docs:dev</code>, open this page, then select <strong>Ormo</strong> in Astro’s toolbar. You should see warnings you can click to highlight the matching element.

</div>
