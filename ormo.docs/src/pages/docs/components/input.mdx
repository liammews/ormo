Input is a thin native <code>&lt;input&gt;</code> wrapper. For labels, descriptions, errors, and validation state, prefer composing it inside <a href="/docs/components/field/">Field</a> (or use <code>Field.Control</code>).

  </DemoBlock>
</div>

## With Field

```astro
---
import * as Field from "@ormo/primitives/field";
import { Input } from "@ormo/primitives/input";
---

<Field.Root name="email" required validationMode="onBlur">
  <Field.Label>Email address</Field.Label>
  <Input type="email" autocomplete="email" />
  <Field.Description>We’ll only use this for account mail.</Field.Description>
  <Field.Error match="valueMissing">Enter your email address.</Field.Error>
</Field.Root>
```

## API reference

Input renders a native <code>&lt;input&gt;</code>, forwards its HTML attributes, and adds <code>data-ormo-input</code> for theming hooks.
