## Anatomy

Each `Tabs.Tab` and `Tabs.Panel` pair shares a unique `value`.

<CodeBlock
  lang="astro"
  code={`---
import * as Tabs from "@ormo/primitives/tabs";
---

<Tabs.Root defaultValue="overview">
  <Tabs.List aria-label="Project">
    <Tabs.Tab value="overview">Overview</Tabs.Tab>
    <Tabs.Tab value="activity">Activity</Tabs.Tab>
  </Tabs.List>
  <Tabs.Panel value="overview">Overview content</Tabs.Panel>
  <Tabs.Panel value="activity">Activity content</Tabs.Panel>
</Tabs.Root>`}
/>

## JavaScript API

The `<ormo-tabs>` element exposes `value`, `orientation`, `activateOnFocus`, `loopFocus` and `disabled`. User selection emits non-cancellable `ormo:value-change` with `{ value }`; direct `value` assignment updates selection without emitting the event.

<CodeBlock
  lang="js"
  code={`tabs.addEventListener("ormo:value-change", (event) => {
  console.log(event.detail.value);
});

tabs.value = "activity";`}
/>

## Styling

Style the consumer classes and public `data-state`, `data-disabled` and `data-orientation` attributes. Active tabs and panels use `data-state="active"`; inactive parts use `"inactive"`. Internal `data-ormo-tabs-*` attributes are runtime ownership selectors.

## Runtime

The server renders complete tab, tablist and panel relationships plus the initial selection. JavaScript adds roving focus, keyboard selection, browser properties and events. Without JavaScript, the initial panel remains visible and the remaining panels remain hidden.
