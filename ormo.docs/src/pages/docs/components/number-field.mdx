## Anatomy

Number Field keeps a native `<input type="number">` as its form control. The other parts add coordinated step controls without replacing native validation or submission.

<CodeBlock lang="astro" code={`---
import * as NumberField from "@ormo/primitives/number-field";
---

<NumberField.Root defaultValue={1} min={0} max={10} name="quantity">
  <NumberField.Group>
    <NumberField.Decrement aria-label="Decrease quantity">−</NumberField.Decrement>
    <NumberField.Input aria-label="Quantity" />
    <NumberField.Increment aria-label="Increase quantity">+</NumberField.Increment>
  </NumberField.Group>
</NumberField.Root>`} />

### Input

Input forwards native number-input attributes except state owned by Root. `name`, `form`, `disabled`, `readOnly`, and `required` can strengthen the corresponding Root values for one input.

### Increment and Decrement

Both parts render `type="button"` and forward native button attributes. They become disabled when Root is disabled or read-only, or when the value reaches the applicable boundary.

### Group

Group renders a `<div role="group">` and forwards native div attributes. It provides a styling container only; the input still needs its own accessible name.

## Browser API

`<ormo-number-field>` exposes `value`, `disabled`, `readOnly`, `min`, `max`, and `step`, plus `increment(multiplier?)` and `decrement(multiplier?)` methods.

The cancellable `ormo:number-field-value-change` event contains `value`, `previousValue`, and a reason of `input`, `keyboard`, `increment`, `decrement`, `wheel`, `programmatic`, or `reset`.

<CodeBlock lang="js" code={`const field = document.querySelector("ormo-number-field");

field.addEventListener("ormo:number-field-value-change", (event) => {
console.log(event.detail.value, event.detail.reason);
});`} />

## Keyboard and pointer behaviour

- Native <kbd>ArrowUp</kbd> and <kbd>ArrowDown</kbd> step the value.
- <kbd>Home</kbd> and <kbd>End</kbd> move to `min` and `max` when supplied.
- <kbd>Alt</kbd> uses `smallStep`; <kbd>Shift</kbd> uses `largeStep`.
- Increment and Decrement clamp step interactions to the supplied range.
- Direct text input stays out of range so native constraint validation can report the problem.
- Wheel stepping is opt-in to prevent accidental page-scroll changes.

## Accessibility and forms

Give Input an accessible name with a native label, `Field.Label`, or `aria-label`. The native input participates in form data, required and range validation, reset, mobile numeric keyboards, and no-JavaScript operation.

## Styling

Number Field ships no visual styles. Public hooks include `data-state="empty|filled"`, `data-disabled`, `data-readonly`, `data-required`, and the part attributes beginning with `data-ormo-number-field-`.

## Scope

This native-first passage intentionally does not include locale-formatted text or pointer scrubbing. Those features require a text parser and hidden form input, which would materially change the no-JavaScript and native validation contract.

## Status

Number Field has production manifest status. The package remains unreleased at version `0.0.0` while this passage of work continues.
