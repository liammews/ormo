## API reference

`Toggle` renders a native `<button>`. It forwards native button attributes, including `name`, `value`, `form`, and `type`.

## JavaScript API

User activation emits cancellable `ormo:pressed-change` with `pressed` and `previousPressed`. Controlled buttons wait for the consumer. `setTogglePressed(button, value)` changes state without an event.

## Accessibility

The native button supplies focus and <kbd>Enter</kbd>/<kbd>Space</kbd> activation. `aria-pressed` supplies toggle state. Give icon-only buttons an accessible name.

## Styling

The toggle has no layout or brand styles. Use `data-state="on" | "off"` and `data-disabled`. `data-ormo-toggle` is an internal runtime selector.
