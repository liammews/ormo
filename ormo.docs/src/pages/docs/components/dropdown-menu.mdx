## Anatomy

Import the namespace and compose a trigger, content, and menu items.

<CodeBlock
  lang="astro"
  code={`---
import * as DropdownMenu from "@ormo/primitives/dropdown-menu";
---

<DropdownMenu.Root>
  <DropdownMenu.Trigger>Actions</DropdownMenu.Trigger>
  <DropdownMenu.Content aria-label="Actions">
    <DropdownMenu.Item>Duplicate</DropdownMenu.Item>
    <DropdownMenu.Item>Rename</DropdownMenu.Item>
    <DropdownMenu.Separator />
    <DropdownMenu.LinkItem href="/help">Help</DropdownMenu.LinkItem>
  </DropdownMenu.Content>
</DropdownMenu.Root>`}
/>

Use `CheckboxItem` for independent options, `RadioGroup` and `RadioItem` for one-of-many options, and `Sub`, `SubTrigger`, and `SubContent` for nested actions. `ItemIndicator` is a visual slot for checked state.

## Positioning

Content uses CSS Anchor Positioning by default. For Floating UI collision handling, set `positioning="floating"` on Root or Sub and load the optional client entry.

<CodeBlock lang="astro" code={`<DropdownMenu.Root positioning="floating">
  <!-- Trigger and Content -->
</DropdownMenu.Root>

<script>
  import "@ormo/primitives/dropdown-menu/floating";
</script>`} />

`side`, `align`, and `sideOffset` changes reposition open content. Floating content exposes `data-resolved-side`, `data-resolved-align`, `--ormo-dropdown-menu-trigger-width`, and `--ormo-dropdown-menu-trigger-height`.

## Browser API and events

`<ormo-dropdown-menu>` exposes the read-only `open` property and the `show()`, `hide()`, and `toggle(force?)` methods.

- `ormo:dropdown-menu-before-select` is cancellable. Prevent it to keep the menu open and stop selection.
- `ormo:dropdown-menu-open-change` reports `open` and a reason: `trigger`, `escape`, `outside`, `tab`, `selection`, or `programmatic`.
- `ormo:dropdown-menu-checked-change` reports the CheckboxItem and its next `checked` value.
- `ormo:dropdown-menu-value-change` reports the RadioItem and its selected `value`.

## Accessibility

The dropdown menu follows the ARIA menu button pattern. The trigger stays in the normal Tab order. Arrow keys open the menu and move focus between items. <kbd>Home</kbd> and <kbd>End</kbd> move to an edge. Printable characters use typeahead. <kbd>Escape</kbd> closes the active menu and restores focus to its trigger. Disabled items stay focusable but cannot run an action.

Submenus open with <kbd>ArrowRight</kbd> in LTR and <kbd>ArrowLeft</kbd> in RTL. The opposite key closes the submenu. Tab closes the menu without trapping focus.

## Styling

The primitive ships only behaviour-critical CSS. Style parts with classes and public attributes such as `data-state`, `data-disabled`, `data-checked`, `data-side`, and `data-align`. Do not force closed popover content to display; the behaviour CSS keeps it hidden until open.
