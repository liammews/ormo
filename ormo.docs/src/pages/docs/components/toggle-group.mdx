`ToggleGroup.Item` renders a native button. Its required `value` identifies selection. `disabled` disables one item. Native button attributes are forwarded.

## JavaScript API

The `<ormo-toggle-group>` element exposes `value`, `disabled`, `required`, `orientation`, `loopFocus`, `name`, `form`, `valid`, `checkValidity()` and `reportValidity()`. User changes emit cancellable `ormo:value-change` with `value`, `previousValue` and `reason`. Reasons are `item`, `programmatic` and `member-removed`.

When `name` is set, selected values are included in `FormData`. Multiple groups submit one entry for each selected value. Form reset restores the server-rendered default selection.

## Accessibility

The root uses `role="group"`. Add `aria-label` or `aria-labelledby`. One enabled item is in the tab order. Horizontal groups use <kbd>Arrow Left</kbd>/<kbd>Arrow Right</kbd>, vertical groups use <kbd>Arrow Up</kbd>/<kbd>Arrow Down</kbd>, and all groups use <kbd>Home</kbd>/<kbd>End</kbd>. Horizontal direction follows Tabs in RTL.

## Styling

The group has no layout or brand styles. Use public `data-state`, `data-disabled`, and `data-orientation` hooks.
