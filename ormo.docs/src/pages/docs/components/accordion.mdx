## Anatomy

Import the component and assemble its parts:

<CodeBlock
  lang="astro"
  code={`---
import * as Accordion from "@ormo/primitives/accordion";
---

<Accordion.Root>
  <Accordion.Item value="value">
    <Accordion.Header>
      <Accordion.Trigger>Trigger label</Accordion.Trigger>
    </Accordion.Header>
    <Accordion.Content>Content</Accordion.Content>
  </Accordion.Item>
</Accordion.Root>`}
/>

### Require an open panel

For `type="single"`, set `collapsible={false}` to prevent the open item from being closed without opening another. This does not choose an initial item, so provide `defaultValue` when a panel must be open from first render. `collapsible` has no effect with `type="multiple"`.

Closed panels are discoverable by the browser’s Find in page feature by default. On this page, search for `OSPREY-742`, then move to the next result to reveal the matching panel. ## JavaScript API

`Accordion.Root` renders an `<ormo-accordion>` custom element for framework-independent client-side control. Its `type`, `collapsible`, `disabled`, and `hiddenUntilFound` properties get or set the corresponding Root configuration. Changing `type` remaps the current value to the matching shape.

The `value` property gets or sets the open value. A single accordion uses `string | null`; a multiple accordion uses `string[]`.

`ormo:value-change` fires after a user interaction or browser-search reveal updates the accordion. It bubbles across shadow boundaries, cannot be cancelled, and includes the updated `value` in `event.detail`. Assigning `value` directly updates the accordion without emitting the event.

<CodeBlock
  lang="js"
  code={`accordion.addEventListener("ormo:value-change", (event) => {
  console.log(event.detail.value);
});

accordion.value = "delivery";
accordion.disabled = true;`}
/>

## Accessibility

Accordion follows the [WAI-ARIA Accordion pattern](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/). Ormo uses native headings and buttons, connects each trigger and panel with ARIA relationships, and keeps every trigger in the normal Tab sequence. Choose the `Accordion.Header` level that fits the surrounding page hierarchy.

## Styling

Accordion ships no layout or brand styles. Pass `class` values to its parts and use the public state hooks below. Attributes prefixed with `data-ormo-*` are internal runtime selectors, not styling APIs.

Closed Content uses `hidden="until-found"`, which retains the Content element’s own layout box. Put padding, borders, and backgrounds on an inner wrapper when they should disappear with the panel.

## Runtime

`Accordion.Root` loads one deduplicated runtime that coordinates state, ARIA relationships, transitions, and browser-search reveals. Initial state is rendered on the server; without JavaScript, any initially open panel remains available but the triggers do not change panels.
