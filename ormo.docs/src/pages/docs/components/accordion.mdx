## Default

The default configuration is a single Accordion with no panel initially open. After the user opens a panel, it remains open until they select another item.

<DemoBlock code={accordionDemoCode}>
  <AccordionDemo />
</DemoBlock>

## Anatomy

Import the component and assemble its parts:

<CodeBlock
  lang="astro"
  code={`---
import * as Accordion from "@ormo/primitives/accordion";
---

<Accordion.Root>
  <Accordion.Item value="delivery">
    <Accordion.Header as="h2">
      <Accordion.Trigger>Delivery</Accordion.Trigger>
    </Accordion.Header>
    <Accordion.Content>Delivery information</Accordion.Content>
  </Accordion.Item>
</Accordion.Root>`}
/>

## Examples

### Initial value

Use <code>defaultValue</code> to select the panel that is open when the Accordion initializes. For a multiple Accordion, pass an array of item values to open more than one panel initially.

<DemoBlock code={accordionInitialValueDemoCode}>
  <AccordionInitialValueDemo />
</DemoBlock>

### Multiple

Use <code>type="multiple"</code> to allow any number of Accordion items to be open.

<DemoBlock code={accordionMultipleDemoCode}>
  <AccordionMultipleDemo />
</DemoBlock>

### Collapsible

Set <code>collapsible</code> on <code>Accordion.Root</code> to let the user close the last open panel.

<DemoBlock code={accordionCollapsibleDemoCode}>
  <AccordionCollapsibleDemo />
</DemoBlock>

### Item disabled

Set <code>disabled</code> on an item to prevent interaction with that item while keeping the rest of the Accordion available. Add <code>disabled</code> to <code>Accordion.Root</code> to disable the entire group of Accordion items.

<DemoBlock code={accordionDisabledDemoCode}>
  <AccordionDisabledDemo />
</DemoBlock>

## Events

Listen for <code>ormo:value-change</code> on the root before the value changes. The event bubbles and crosses shadow boundaries. Changes from user interaction can be canceled with <code>preventDefault()</code>. A change that reveals a browser Find in Page match is not cancelable, because the browser must be able to reveal the matched content.

Listen for <code>ormo:open-change</code> after an individual item opens or closes. Its detail contains the item’s <code>value</code> and new <code>open</code> state.

<CodeBlock
  lang="js"
  code={`accordion.addEventListener("ormo:value-change", (event) => {
  console.log(event.detail.value);
});

accordion.addEventListener("ormo:open-change", (event) => {
${String.fromCharCode(32, 32)}console.log(event.detail.value, event.detail.open);
});`}
/>

## Keyboard behavior

Every trigger is a native button in the normal Tab sequence. Use <kbd>Enter</kbd> or <kbd>Space</kbd> to toggle it. Accordion does not capture Arrow, Home, or End keys.

## Styling

Item, Header, Trigger, and Content expose <code>data-open</code>, <code>data-disabled</code>, and <code>data-index</code>. Root exposes <code>data-disabled</code> and <code>data-orientation</code>. The existing <code>data-state="open|closed"</code> attribute remains available for explicit state selectors.

Content exposes <code>data-starting-style</code> and <code>data-ending-style</code> during transitions, along with <code>--ormo-accordion-content-height</code> and <code>--ormo-accordion-content-width</code>.
