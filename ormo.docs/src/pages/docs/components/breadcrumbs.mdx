## Usage

Use breadcrumbs to show a page’s position within a hierarchical site structure and provide links to its ancestors. Place the current page last and mark it with `Breadcrumbs.Page`, or use `Breadcrumbs.Link current` when the current page should remain a link.

Do not use breadcrumbs to represent browsing history, a linear progress indicator, or the site’s primary navigation. Omit the trail when it would contain only the current page.

Use `Breadcrumbs.Separator` for visual punctuation between items. It keeps the separator out of the accessibility tree while preserving valid ordered-list markup.

## Anatomy

Import the component and assemble its parts:

<CodeBlock
  lang="astro"
  code={`---
import * as Breadcrumbs from "@ormo/primitives/breadcrumbs";
---

<Breadcrumbs.Root>
  <Breadcrumbs.List>
    <Breadcrumbs.Item>
      <Breadcrumbs.Link href="/parent-page">Parent page</Breadcrumbs.Link>
    </Breadcrumbs.Item>
    <Breadcrumbs.Separator>/</Breadcrumbs.Separator>
    <Breadcrumbs.Item>
      <Breadcrumbs.Page>Current page</Breadcrumbs.Page>
    </Breadcrumbs.Item>
  </Breadcrumbs.List>
</Breadcrumbs.Root>`}
/>

## Accessibility

The breadcrumbs follow the WAI-ARIA breadcrumb pattern using native HTML: `Breadcrumbs.Root` creates a named navigation landmark, `Breadcrumbs.List` communicates the trail’s order, and the current crumb exposes `aria-current="page"`.

Include exactly one current crumb in each trail. Use `Breadcrumbs.Page` by default so the current location is not needlessly linked, or `Breadcrumbs.Link current` when retaining the link serves a concrete navigation need. When a page contains more than one breadcrumb landmark, give each `Breadcrumbs.Root` a distinct accessible name.

Render visual punctuation with `Breadcrumbs.Separator`. Do not generate textual separators with CSS `content`, because browsers can expose generated text to assistive technology.

## Styling

The breadcrumb primitives ship no layout or brand styles. Pass `class` or `style` to each part to control layout, typography, colour and separator presentation. Style the current crumb with `[aria-current="page"]`; attributes prefixed with `data-ormo-*` are internal markers rather than public styling APIs.

Use flex wrapping or another reflow-safe layout for long trails. Avoid fixed heights and truncation that remove the current page or make ancestor links unavailable at narrow viewport widths or increased text size.

## Runtime

The breadcrumb component ships no client-side JavaScript. The navigation landmark, current-page state, separators, and optional structured data are rendered entirely on the server and remain available when JavaScript is disabled.
