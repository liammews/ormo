Breadcrumbs render a navigation landmark with an ordered list of ancestor links and the current page. The primitive ships no client JavaScript.

## Default

The safest default marks the current page with <code>Breadcrumbs.Page</code> (a non-link <code>&lt;span aria-current="page"&gt;</code>) and places decorative separators in their own list items so they stay out of the accessibility tree.

## Anatomy

Import the namespace and assemble the trail:

<CodeBlock
  lang="astro"
  code={`---
import * as Breadcrumbs from "@ormo/primitives/breadcrumbs";
---

<Breadcrumbs.Root>
  <Breadcrumbs.List>
    <Breadcrumbs.Item>
      <Breadcrumbs.Link href="/books">Books</Breadcrumbs.Link>
    </Breadcrumbs.Item>
    <Breadcrumbs.Separator />
    <Breadcrumbs.Item>
      <Breadcrumbs.Page>Award Winners</Breadcrumbs.Page>
    </Breadcrumbs.Item>
  </Breadcrumbs.List>
</Breadcrumbs.Root>`}
/>

Use <code>Link current</code> when the current crumb should remain a link. Ormo sets <code>aria-current="page"</code> on that link. Prefer <code>Page</code> when the current location should not navigate.

### Microdata

Set <code>microdata</code> on Root to annotate the trail as Schema.org <code>BreadcrumbList</code>. Ormo adds <code>itemscope</code> / <code>itemtype</code> / <code>itemprop</code> attributes and sequential <code>position</code> values. By default, each link wraps its slot in <code>&lt;span itemprop="name"&gt;</code>. Pass <code>name</code> on <code>Link</code> or <code>Page</code> to emit a <code>&lt;meta itemprop="name"&gt;</code> sibling instead when the wrapper would disturb layout.

## Accessibility

Breadcrumbs follow the [APG Breadcrumb pattern](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/):

- The trail is a navigation landmark. Root defaults <code>aria-label</code> to <code>"Breadcrumb"</code>, or use <code>aria-labelledby</code> with a visible heading.
- Mark exactly one current page with <code>Page</code> or <code>Link current</code>.
- Separators must not be announced. <code>Separator</code> uses <code>role="presentation"</code> and <code>aria-hidden="true"</code>; CSS-only separators never enter the accessibility tree.
- Style the current crumb with <code>[aria-current="page"]</code>. Ormo does not add a redundant <code>data-current</code> attribute.
- Provide meaningful link text (WCAG 2.4.4). Empty links warn in development.

## Keyboard behaviour

No composite keyboard model. Links participate in the normal Tab sequence and activate with the browser’s native link keys.

## Styling

Consumers own classes. Useful hooks:

| Selector / attribute                           | Meaning                                |
| ---------------------------------------------- | -------------------------------------- |
| <code>[data-ormo-breadcrumbs-root]</code>      | Root nav (internal; prefer your class) |
| <code>[data-microdata]</code>                  | Microdata mode is on                   |
| <code>[aria-current="page"]</code>             | Current page crumb                     |
| <code>[data-ormo-breadcrumbs-separator]</code> | Decorative separator item              |

Attributes prefixed with <code>data-ormo-\*</code> are internal runtime/structure selectors, not a public styling API.

## Runtime

Breadcrumbs is a static primitive. It ships no client JavaScript in development or production. Microdata, positions, and accessible names are resolved during SSR.
