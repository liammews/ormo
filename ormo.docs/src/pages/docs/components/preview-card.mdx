## Anatomy

`PreviewCard.Trigger` renders a link. Keep all essential information available on its destination page.

<CodeBlock lang="astro" code={`---
import * as PreviewCard from "@ormo/primitives/preview-card";
---

<PreviewCard.Root>
  <PreviewCard.Trigger href="/astro">Astro</PreviewCard.Trigger>
  <PreviewCard.Content>
    <strong>Astro</strong>
    <p>The web framework for content-driven websites.</p>
  </PreviewCard.Content>
</PreviewCard.Root>`} />

## Positioning

Preview Card uses CSS Anchor Positioning by default. To use Floating UI collision handling, set `positioning="floating"` and load its optional client entry.

<CodeBlock lang="astro" code={`<PreviewCard.Root positioning="floating">
  <!-- Trigger and Content -->
</PreviewCard.Root>

<script>
  import "@ormo/primitives/preview-card/floating";
</script>`} />

`ormo:preview-card-open-change` bubbles and crosses shadow boundaries. It is not cancellable. Its detail contains `open` and a `reason` of `"focus"`, `"pointer"`, `"escape"`, `"trigger"`, or `"programmatic"`.

<CodeBlock lang="js" code={`const preview = document.querySelector("ormo-preview-card");

preview.addEventListener("ormo:preview-card-open-change", (event) => {
console.log(event.detail.open, event.detail.reason);
});

preview.show();`} />

## Accessibility

The preview is a visual enhancement. It is hidden from assistive technology and does not describe the trigger. Do not put unique information or interactive controls in `PreviewCard.Content`. The link remains usable without JavaScript, pointer input, or access to the preview.

Pointer interest opens the preview after a delay. Focusing the link can also display it, but focus stays on the link. <kbd>Escape</kbd> closes an open preview.

## Styling

Preview Card ships no layout or brand styles. Style the parts through `class` or public state hooks such as `[data-state="open"]`, `[data-starting-style]`, and `[data-ending-style]`.

Content stays hidden while its native popover is closed, even when a consumer class sets `display`. Apply layout either to an inner wrapper or with `:popover-open`:

<CodeBlock
  lang="css"
  code={`.preview-card-content:popover-open {
  display: grid;
}`}
/>

Content exposes `--ormo-preview-card-trigger-width` and `--ormo-preview-card-trigger-height` while Floating UI is active. `side`, `align`, and `sideOffset` changes reposition an open preview.
