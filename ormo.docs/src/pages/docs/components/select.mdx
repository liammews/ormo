## Anatomy

Import the parts and provide a trigger, value display, content and items. `Select.Clear`, groups and separators are optional.

<CodeBlock
  lang="astro"
  code={`---
import * as Select from "@ormo/primitives/select";
import { Check } from "@lucide/astro";
---

<label for="country-control">Country</label>
<Select.Root id="country" name="country">
  <Select.Trigger>
    <Select.Value placeholder="Choose a country" />
    <Select.Icon>⌄</Select.Icon>
  </Select.Trigger>
  <Select.Clear aria-label="Clear country">×</Select.Clear>
  <Select.Content>
    <Select.Group>
      <Select.GroupLabel>Europe</Select.GroupLabel>
      <Select.Item value="fr">
        France
        <Select.ItemIndicator>
          <Check aria-hidden="true" />
        </Select.ItemIndicator>
      </Select.Item>
      <Select.Item value="gb">
        United Kingdom
        <Select.ItemIndicator>
          <Check aria-hidden="true" />
        </Select.ItemIndicator>
      </Select.Item>
    </Select.Group>
  </Select.Content>
</Select.Root>`}
/>

For a custom select with `id="country"`, Ormo gives its native control the id `country-control`. Point a visible label at that control; Ormo transfers the accessible name and redirects label focus to the enhanced trigger.

### Rich item content

Items may contain non-interactive presentation. Pass `textValue` when the visible text cannot be reliably inferred; Ormo uses it for typeahead, the trigger value and the native fallback.

```astro
<Select.Item value="gb" textValue="United Kingdom">
  <Flag code="gb" aria-hidden="true" />
  <span>United Kingdom</span>
</Select.Item>
```

Do not put buttons, links or other interactive controls inside an item.

### Trigger

Renders `<button type="button" role="combobox">`. It owns focus, expanded state and active-option relationships. Give it an accessible name directly or label the underlying native control.

### Value

Renders `<span>` and displays the selected item’s text. `placeholder` supplies the empty display and the native empty-value fallback option.

### Icon

Renders an `aria-hidden` `<span>` for a decorative picker affordance.

### Clear

Renders `<button type="button">`, clears the value to `""`, and is disabled while the select is empty or disabled. Provide visible text or an accessible name. It is available only in custom mode.

### ItemIndicator

Renders an `aria-hidden` `<span>` in custom mode and renders nothing in native mode. Place a real icon inside it to mark the selected item. Ormo keeps the indicator hidden while its parent item is not selected, and indicator content is excluded from inferred item text.

### Group and GroupLabel

`Group` renders an accessible option group and requires a `GroupLabel`. Custom groups after the first receive an automatic separator; native mode renders `<optgroup>` with the label text.

### Separator

Renders a non-selectable horizontal separator in custom mode and `<hr>` in native mode. It is skipped by keyboard navigation and typeahead.

## Browser API and events

Custom `Select.Root` exposes `value`, `disabled`, and read-only `open` properties plus `show()`, `hide()`, and `toggle(force?)`. Direct `value` assignment updates immediately and dispatches `ormo:select-value-change` with a `"programmatic"` reason, but does not synthesize native `input` or `change` events.

User changes first dispatch cancellable `ormo:select-before-value-change`, with `value`, `previousValue`, and `reason`. When allowed, Ormo updates the native control, dispatches native `input` and `change`, then dispatches `ormo:select-value-change`. `ormo:select-open-change` reports popup changes and their reason.

To use Floating UI positioning:

```astro
---
import "@ormo/primitives/select/floating";
---

<Select.Root positioning="floating">…</Select.Root>
```

## Accessibility

Custom mode follows the WAI-ARIA select-only combobox pattern. DOM focus remains on the trigger while `aria-activedescendant` identifies the highlighted option. Groups have accessible names, disabled options are skipped, and the popup is not part of the page’s Tab sequence.

Use a Combobox instead when users need to filter a large collection.

## Runtime

Custom mode initially shows the server-rendered native select. After the runtime has successfully prepared the custom interface it adds `data-enhanced`, visually hides the native control and reveals the custom trigger. If JavaScript does not load, the native picker remains usable. Native mode ships no Select JavaScript.
