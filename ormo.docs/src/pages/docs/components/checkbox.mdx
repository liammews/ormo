Checkbox is a native <code>&lt;input type="checkbox"&gt;</code>. A standalone
checkbox ships no client JavaScript unless you set <code>indeterminate</code>.
Use <a href="#checkbox-group">CheckboxGroup</a> when several checkboxes share a
name, parent select-all, or group-level validation.

### Checkbox group

Group members inherit <code>name</code>, initial checked state from

<code>defaultValue</code>, and group <code>disabled</code>. The group always
loads a small custom-element runtime and exposes aggregate
<code>data-state</code> of <code>none</code>, <code>partial</code>, or
<code>all</code>.

### Parent select-all

Set <code>parent</code> on a checkbox inside a group. It never submits

<code>name</code> or <code>value</code>. Its checked and mixed state derive from
every member, including disabled ones. Toggling it only writes to enabled
members.

<code>CheckboxGroup.Label</code>, not <code>Field.Label</code>. For at-least-one
validation, set <code>required</code> and <code>requiredMessage</code> on the
group.

### CheckboxGroup.Label

Renders a <code>&lt;span&gt;</code> linked with <code>aria-labelledby</code>. Do
not use a <code>&lt;label&gt;</code> for the group name — a group is not a
labelable element.

## Browser API and events

<code>ormo-checkbox-group</code> exposes:

- <code>value: string[]</code> — checked member values; assignable
- <code>name</code>, <code>disabled</code>, <code>required</code>,
  <code>requiredMessage</code>
- <code>checkValidity()</code> / <code>reportValidity()</code>
- <code>ormo:value-change</code> with <code>detail.value: string[]</code>

A standalone Checkbox keeps the native input API:

<code>checked</code>, <code>indeterminate</code>, and <code>change</code>.

## Accessibility

- Prefer a wrapping <code>&lt;label&gt;</code> or a sibling label with
  <code>for</code>/<code>id</code>.
- Name groups with <code>CheckboxGroup.Label</code>, <code>aria-label</code>, or
  <code>aria-labelledby</code>.
- Do not hide the native control with <code>display: none</code> or zero size.
- Decorative icons belong in <code>CheckboxIndicator</code> or another
  <code>aria-hidden</code> sibling.

## Keyboard behaviour

| Key             | Effect                                     |
| --------------- | ------------------------------------------ |
| Space           | Toggles the focused checkbox               |
| Tab / Shift+Tab | Moves between checkboxes in document order |

Arrow keys are not handled. Every checkbox stays in the normal Tab sequence,
matching the WAI-ARIA checkbox pattern (and differing from Tabs’ composite
keyboard model).

## Styling

Style checkboxes with native pseudo-classes:

- <code>:checked</code>, <code>:indeterminate</code>, <code>:disabled</code>,
  <code>:required</code>, <code>:invalid</code>, <code>:focus-visible</code>
- Group aggregate state: <code>[data-state="none\|partial\|all"]</code> on
  <code>ormo-checkbox-group</code>
- Field-derived attributes on the group when composed with Field:
  <code>data-invalid</code>, <code>data-filled</code>, <code>data-dirty</code>,
  and related

For the simplest brand colour, use <code>accent-color</code>. For full control,
use <code>appearance: none</code> and keep forced-colours fallbacks in mind.

## Runtime

| Configuration              | JavaScript                                                               |
| -------------------------- | ------------------------------------------------------------------------ |
| Standalone Checkbox        | None                                                                     |
| <code>indeterminate</code> | Small opt-in module                                                      |
| CheckboxIndicator          | CSS only (<code>pointer-events: none</code>); diagnostics in development |
| CheckboxGroup              | Always-on custom element                                                 |

## Development toolbar

The Ormo development toolbar warns about missing accessible names, parent
checkboxes outside a group, indicators that are not siblings of a checkbox, and
unnamed groups.
