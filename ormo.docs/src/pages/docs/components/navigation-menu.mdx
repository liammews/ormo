## Anatomy

Use `Link` for direct destinations. Combine `Trigger` and `Content` when one item exposes a group of navigation links.

<CodeBlock lang="astro" code={`---
import * as NavigationMenu from "@ormo/primitives/navigation-menu";
---

<NavigationMenu.Root aria-label="Main navigation" positioning="floating">
  <NavigationMenu.List>
    <NavigationMenu.Item value="products">
      <NavigationMenu.Trigger>Products</NavigationMenu.Trigger>
      <NavigationMenu.Content side="bottom" align="start" sideOffset={6}>
        <a href="/analytics">Analytics</a>
      </NavigationMenu.Content>
    </NavigationMenu.Item>
    <NavigationMenu.Item value="about">
      <NavigationMenu.Link href="/about">About</NavigationMenu.Link>
    </NavigationMenu.Item>
  </NavigationMenu.List>
</NavigationMenu.Root>

<script>
  import "@ormo/primitives/navigation-menu/floating";
</script>`} />

Dropdown content keeps ordinary document semantics. Do not add `menu` or `menuitem` roles. Tab follows normal document order, and modified clicks on links retain native browser behaviour.

`Content` accepts `side`, `align`, and `sideOffset`. Import `@ormo/primitives/navigation-menu/floating` from a client script when Root uses `positioning="floating"`.

All parts forward their relevant native attributes. `Item.value` is required for coordinated disclosure state.
