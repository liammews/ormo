## Anatomy

Use a switch for a setting that takes effect when it changes. Use a checkbox
when the value is part of a form task or when the user must confirm it before
submission.

`Switch.Root` contains the native control. `Switch.Thumb` is decorative and
shows the current position.

<CodeBlock
  lang="astro"
  code={`---
import * as Switch from "@ormo/primitives/switch";
---

<label>
  <Switch.Root name="notifications" defaultChecked>
    <Switch.Thumb />
  </Switch.Root>
  Notifications
</label>`}
/>

## Examples

### Form validation

The switch uses a native checkbox input. It supports native form submission,
external form association, required validation, and reset. An off switch does
not submit a value.

## JavaScript API

The `<ormo-switch>` element exposes `checked`, `disabled`, `readOnly`,
`required`, `name`, `value`, read-only `form`, read-only `valid`,
`checkValidity()`, and `reportValidity()`.

`ormo:switch-before-checked-change` fires before a user change. It is
cancellable. `ormo:switch-checked-change` fires after user, programmatic, and
reset changes. Both events bubble and cross shadow boundaries. Event detail
includes `checked`, `previousChecked`, and `reason`.

<CodeBlock
  lang="js"
  code={`const switchElement = document.querySelector("ormo-switch");

switchElement.addEventListener("ormo:switch-checked-change", (event) => {
console.log(event.detail.checked, event.detail.reason);
});

switchElement.checked = true;`}
/>

## Accessibility

The native checkbox input has `role="switch"`. Give every switch an accessible
name with a wrapping `<label>`, a sibling label with `for` and `id`,
`aria-label`, or `aria-labelledby`.

## Runtime

The server renders a labelled native switch, its form state, and its styling
hooks. JavaScript synchronises composed state, readonly interaction, events,
and the DOM API. Before JavaScript loads, a readonly switch is disabled so it
cannot change. Enhancement makes it focusable while keeping it immutable.
Other switches remain toggleable, valid, and submittable without JavaScript.
